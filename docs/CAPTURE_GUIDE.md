# Quest capture

기본 수집 경로는 [한 앱에서 RGB + Skeleton + AprilTag](UNIFIED_CAPTURE.md)입니다.

통합 버전은 소프트웨어 검증 단계이며 APK/hardware 검증은 아직 완료되지 않았습니다.

이전 실물 녹화가 확인된 보조 앱 방식은 [legacy companion 안내](LEGACY_COMPANION.md)에 보존합니다.

통합 녹화 기본 저장 경로는 ~/Warp_data/YYYY-MM-DD/1, 2, ... 입니다. 폴더를 원자적으로 예약하므로 기존 녹화를 덮어쓰지 않습니다. --session은 metadata label로 보존됩니다.
