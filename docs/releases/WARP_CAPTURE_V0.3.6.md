# Warp capture v0.3.6 — NECK idle timeout

NECK 진입 후 녹화 없이 20분 대기하면 HEAD로 자동 복귀하고 근접센서 무시를 해제합니다. 녹화 준비·카운트다운·녹화·저장 중에는 센서 무시를 유지합니다. 실제 녹화 종료와 네이티브 저장 종료 후 20분을 새로 계산합니다. 카운트다운 취소나 녹화 시작 실패는 기존 대기 시간을 이어갑니다.

## 포함된 변경

- 볼륨 업: 3 → 2 → 1 카운트다운 후 녹화 시작, 다시 누르면 종료.
- 볼륨 다운: 대기 중 HEAD/NECK 전환과 착용 모드 HUD 표시.
- NECK에서는 2초마다 6초 근접센서 무시 요청을 갱신하며, 일시적인 VR 포커스 변경에도 유지합니다.
- Android의 단조 증가 시계로 대기 시간을 계산하며, 자동 HEAD 복귀를 Unity 표시와 저장 설정에 동기화합니다.
- 원본 영상·추적 데이터에 착용 모드를 기록합니다. Meta 골격의 해부학적 보정이나 목 착용 정확도 검증을 추가한 것은 아닙니다.
- 원본 take는 날짜/UUID 경로에 저장하고 처리 결과는 take 내부 processed/에 배치합니다.

## 검증

- Unity Android APK 빌드, 네이티브 Java 단독 컴파일, 이전 APK와 서명 일치 확인.
- Quest에 앱 버전 3.0.6-raw / versionCode 30006 설치 확인.
- 관련 Python 테스트 59개와 subtest 4개 통과. pydrake가 없는 환경에서 retarget 테스트는 제외했습니다.
- 가상 시계 테스트: 20분 경계, 60분 녹화 중 센서 무시 유지, 녹화 종료 후 타이머 초기화, 취소 시 초기화 없음, 반복 동기화, 포커스 변경, 모드 재진입 검증.
- 기기 vrpowermanager에서 NECK의 6초 요청이 2초마다 수신되는 것을 확인했습니다.

## 실기 검증 범위

이번 버전의 실제 20분 대기와 새 물리 녹화 시험은 아직 수행하지 않았습니다. ADB 볼륨 다운 주입을 통한 HEAD 복구는 관측되지 않아 이번 버전에서 확인 완료로 표기하지 않습니다. 목 착용 골격 정확도와 카메라/추적 시계 정렬은 별도 검증이 필요합니다.

## 설치

기존 Warp 패키지 위에 APK를 업데이트 설치합니다. 사용자 데이터는 유지됩니다.

```bash
adb install -r warp-capture-v0.3.6.apk
```

패키지: com.GTSafeRoboticsLab.xrteleopclient.warp

APK 무결성은 함께 배포하는 SHA256SUMS로 확인할 수 있습니다. verification.json에는 설치 APK와 소스의 SHA-256 및 검증 범위를 기록했습니다.
